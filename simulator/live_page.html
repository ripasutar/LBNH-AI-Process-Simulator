How the AI simulator was built, and how to check it did not copy Aspen

The Python simulator was built in three steps. Aspen data entered only where stated below, and every step can be checked by anyone with the files.
1
Blind build, before any Aspen result Given: Table 1 feed of my paper, the block diagram, the technologies (C3MR; N₂ and He refrigeration; Collins liquefier) and the property method. Everything else the AI designed itself; each number is labelled GIVEN / CHOSEN / TYPICAL in design_basis.py. Predictions sealed on 25 Sep 2026 in predictions_sealed.json with a SHA-256 hash: LNG 555.8 t/h, liquid helium 807 kg/h (Aspen: 541.4 t/h, 820 kg/h). The blind power was 192 MW against Aspen's 332.5 MW, because the AI chose its own pressures and efficiencies: a copied result could not differ like this.
2
Same-design check, with my Aspen settings Given (inputs only): pressures, temperatures, compressor efficiencies, refrigerant composition and inlet states from my Aspen file (aspen_settings.json). Computed by Python: power of every machine, 331.4 MW total against Aspen's 332.5 MW (−0.3 %). Aspen's power results are used only for the comparison column, never in the calculation.
3
What-if studies For a new feed, Python solves the whole plant again: thermodynamics, flashes, the main exchanger, the boil-off recycle, the N₂ column and the helium liquefier (about 30–40 s). Results are then shown on my Aspen basis (see the table below), so the numbers start exactly from my published design.

Check it yourself

  1. The seal: on Windows run certutil -hashfile predictions_sealed.json SHA256 in the simulator folder. It must print d0ea425b…7af69, the value in predictions_sealed.sha256, so the blind predictions have not been changed. (The hash proves the file is unchanged; the seal date is the one written inside the file.)
  2. Change an Aspen setting: edit a compressor efficiency or pressure in aspen_settings.json and run python same_design.py. The power changes accordingly; a copied number would not.
  3. Change the feed: press Solve in tab 1; the black window shows the real iterations (recycle, column) for 30–40 s.
  4. Read the code (tab 3): Aspen results appear only in live_app.py (the ASPEN block, for the Aspen basis and the comparison) and in the settings files; the thermodynamics, flash, column, exchanger and liquefier code contain no Aspen results.
